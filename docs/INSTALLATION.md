# Installation on Windows and macOS

Python **3.11 or 3.12 (64-bit)** is recommended. The project supports Python
3.10–3.14, but 3.11/3.12 offers the safest compatibility range for the saved
scientific and machine-learning models.

Always work from the project root: the directory containing `README.md`,
`requirements.txt`, `models/` and `Utility/`.

## Windows 10/11 — PowerShell

1. Install 64-bit Python from <https://www.python.org/downloads/windows/>.
   During installation, enable **Add Python to PATH**.
2. Open PowerShell inside the TiLDe directory.
3. Run:

```powershell
py -3.12 -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m ipykernel install --user --name tilde --display-name "Python (TiLDe)"
python -m jupyter lab
```

If `py -3.12` is unavailable, use `python` after checking
`python --version`.

### Optional NVIDIA acceleration

The normal installation is CPU-compatible. For an NVIDIA GPU, use the command
generated by the official PyTorch selector at
<https://pytorch.org/get-started/locally/> for the installed CUDA version, then
rerun `python -m pip install -r requirements.txt`.

## macOS — Terminal

1. Install a native Python 3.12 build from
   <https://www.python.org/downloads/macos/>. On Apple Silicon, use the arm64 /
   universal installer.
2. Open Terminal inside the TiLDe directory.
3. Run:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m ipykernel install --user --name tilde --display-name "Python (TiLDe)"
python -m jupyter lab
```

If the command is `python3` rather than `python3.12`, substitute it in the first
line. Apple Silicon machines can use PyTorch's MPS backend. The inference
modules select `mps` automatically when it is available; Intel Macs use CPU.

## Core-only installation

For preprocessing, plotting and both time-delay methods without neural-network
or Catch22 inference:

```bash
python -m pip install -r requirements-core.txt
```

This lighter installation does not install PyTorch, `sktime` or JupyterLab.

## Verification

With the environment activated:

```bash
python -m compileall -q Utility
python -m Utility.time_delay_interpolation --help
python -m Utility.time_delay_pspline --help
python tests/smoke_test.py
```

Expected final line:

```text
TiLDe smoke tests: OK
```

## Opening the notebooks

Start JupyterLab from the project root:

```bash
python -m jupyter lab
```

Open `notebooks/00_start_here.ipynb` and select the **Python (TiLDe)** kernel.

## Common installation problems

| Symptom | Resolution |
|---|---|
| `python` or `py` not found | Reinstall Python and enable PATH, then open a new terminal. |
| PowerShell blocks `Activate.ps1` | Run the process-scoped `Set-ExecutionPolicy` command shown above. |
| `No module named Utility` | Launch Jupyter from the project root, not from `notebooks/`. |
| `No module named torch` or `sktime` | Install `requirements.txt`, not only `requirements-core.txt`. |
| CUDA requested but unavailable | Use `--device auto` or `--device cpu`. |
| Apple MPS error for one operation | Rerun with `--device cpu`; the saved model remains unchanged. |
| Saved model fails after a package upgrade | Recreate `.venv` from this requirements file before modifying code. |
